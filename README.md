# 📁 File Organizer (Python)

A Python script that organizes files in a folder based on file type. It creates folders like Images, Videos, Documents, and moves files accordingly.

## 🔧 Tech Used:
- Python
- OS module
- Shutil module

## 💡 How It Works:
1. Define file types and folders
2. Loop through files in selected directory
3. Move files based on extensions

## ✅ Example:
Downloads/
├── Images/
├── Videos/
├── Documents/
├── Others/
